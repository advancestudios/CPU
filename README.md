# ¿Qué puedes hacer con el Bot? 💡

Con CPU bot, puedes hacer una gran cantidad de cosas.

__A continuación__ se mostraran una serie de comandos con descripcion que el bot posee actualmente.

### Comandos Slash
- Categoria: **Moderación**
1. `/kick` — Expulsa a un miembro
2. `/ban` — Banea a un miembro
3. `/unban` — Revoca un baneo
4. `/mute` — Silencia temporalmente
5. `/unmute` — Remueve el silencio
6. `/warn` — Registra una advertencia
7. `/warns view` — Consulta el historial de advertencias
8. `/warns clear` — Limpia el historial de advertencias (No posee un comando para eliminar warns individualmente)
9. `/role add` — Asigna un rol
10. `/role remove` — Remueve un rol
11. `/clear` — Elimina mensajes (Por cantidad)

### Comandos Slash
- Categoria: **Utilidad**
1. `/nick` — Cambia tu apodo o el de otro miembro
2. `/userinfo` — Información de un miembro
3. `/cmdcheck` — Verifica los permisos de un miembro
4. `/postularse` — Inicia tu proceso de postulación
5. `/set canal postulaciones` — Configura el canal de postulaciones

### Comandos Prefijo
- Categoria: **General**
1. `;ping` — Verifica la latencia del bot
2. `;help` — Muestra un panel tipo embed, mostrando todos los comandos actuales
3. `;botinvite` — Obtén el enlace para invitar al bot
4. `;serverinvite` — Recibe la invitación de este servidor por MD
5. `;lock` — Bloquea el canal actual
6. `;unlock` — Desbloquea el canal actual

# ¿Dónde/Como agrego el Bot a mi Server?🤔
- Ahora que el bot esta verificado, puedes obtenerlo oficialmente desde la pagina de Descubrimiento de Discord!🎉

  - Pasos para agregar al bot a tu servidor
  En Discord para PC:
  1. Abre Discord.
  2. En el panel izquierdo, ve a **Descubrir >> Aplicaciones**
  3. En el apartado de búsqueda arriba a la derecha, escribe **CPU** y presiona Enter.
  4. Búscalo como **CPU**, y cuando lo encuentres haz clic en él.
  5. Selecciona **Añadir** >> **Añadir a Servidor** >> **Selecciona tu servidor de preferencia** >> **Autoriza**, y Listo.
